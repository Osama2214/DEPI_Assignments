## Topics Covered

The repository includes practice and assignments related to the
following C# and .NET topics, depending on the assignment:

-   Variables and data types
-   Conditional statements and loops
-   Arrays and strings
-   Methods and basic problem solving
-   Object-Oriented Programming (OOP)
-   Classes, objects, inheritance, and polymorphism
-   Static and dynamic binding
-   Interfaces
-   Delegates and built-in generic delegates (`Func<>`, `Action<>`, and
    `Predicate<>`)
-   Lambda expressions and anonymous methods
-   Events and multicast delegates
-   Additional C# language features and practice exercises
